# لوحة مفاتيح المساوى — AL-MASAWI KEYBOARD
«اكتب بإبداع... وتحدث بلا حدود»

لوحة مفاتيح Android حقيقية (`InputMethodService`) بحزمة `com.almasawi.keyboard`.

## حالة المشروع (v0.1.0)

**مكتمل في الكود (لم يُبنَ بعد):**
- محرك لوحة المفاتيح: View مرسوم بـ Canvas، لمس متعدد، تكرار الحذف عند الضغط المطول، بدائل الحروف بالضغط المطول (مع انزلاق الإصبع للاختيار)، سحب أفقي على المسافة لتحريك المؤشر.
- تخطيط عربي (RTL حقيقي) مع طبقة Shift للتشكيل وأشكال الهمزة وعلامات الترقيم العربية، وتخطيط إنجليزي، وتخطيطا رموز.
- صف أرقام اختياري، وأرقام غربية/هندية، وبدائل بالضغط المطول للكتابة المختلطة.
- زر Enter يتكيف مع الحقل (بحث/إرسال/التالي/تم/اذهب/سطر جديد).
- فتح لوحة الرموز في حقول الأرقام والهاتف، والإنجليزية في البريد والروابط وكلمات المرور.
- 8 ثيمات، اهتزاز، صوت، ارتفاع المفاتيح، إعدادات محفوظة في DataStore.
- تطبيق Compose: حالة التفعيل، اختيار اللوحة، حقل تجربة، الثيمات مع معاينة مباشرة، الإعدادات، الخصوصية.
- لا صلاحيات في AndroidManifest إطلاقاً.

**غير منفَّذ بعد (لا توجد أزرار وهمية له في الواجهة):**
اقتراحات الكلمات والتصحيح، الحافظة، الإيموجي، القوالب، الذكاء الاصطناعي، الإملاء الصوتي،
الكتابة بالسحب، الوضع العائم، الكتابة بيد واحدة، شاشتا البداية والترحيب، شاشات اللغات والتخصيص المتقدم.

## البناء
البناء على GitHub Actions: `.github/workflows/build.yml`
(اختبارات الوحدة ← lint ← APK debug ← APK release عند وجود أسرار التوقيع).

أسرار التوقيع المطلوبة للإصدار: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

> الـ workflow يستخدم `gradle` (الإصدار 8.7 عبر setup-gradle) ولا يحتاج Gradle wrapper.
> lint حالياً غير مانع للبناء (`abortOnError=false`) ويُرفع تقريره كـ Artifact.

## البنية
```
ime/        خدمة IME وحالة التفعيل ومحلل زر Enter
keyboard/   KeyboardView (الرسم واللمس) و KeyboardController (منطق الإدخال)
layouts/    Key و LayoutFactory (العربية، الإنجليزية، الرموز)
themes/     الثيمات
settings/   DataStore
privacy/    سياسة الحقول الحساسة
ui/         شاشات Compose
```
